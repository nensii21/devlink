# Reusable Loading State Library (#621)

Standardized loading components for DevLink.

## Components
- Skeleton Card (`SkeletonCard`)
- Skeleton Table (`SkeletonTable`)
- Skeleton Profile (`SkeletonProfile`)
- Spinner (`Spinner`)
- Progress Bar (`ProgressBar`)
- Full Page Loader (`FullPageLoader`)

## How to Test
1. **Frontend Typecheck**: `npm --prefix frontend run typecheck`
2. **Showcase UI**: Navigate to `/loading-states` route.
