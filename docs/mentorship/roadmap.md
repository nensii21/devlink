# Beginner Onboarding Roadmap

Follow these 4 phases to get up to speed with the repository:

### Phase 1: Environment Setup & Exploration (Days 1–2)
- Fork and clone the [devlink repository](https://github.com/nensii21/devlink).
- Install dependencies (`npm install` or preferred package manager).
- Run the app locally and explore the UI components.
- Review our [Code of Conduct](https://github.com/nensii21/devlink/blob/main/CODE_OF_CONDUCT.md).

### Phase 2: Finding Your First Issue (Days 3–4)
- Browse issues tagged with `good first issue` or `beginner`.
- Comment on the issue to express your interest and get assigned.

### Phase 3: Development & Local Testing (Days 5–8)
- Create a dedicated feature/bugfix branch (`git checkout -b feature/my-first-contribution`).
- Write clean code adhering to our linter rules.
- Test your changes thoroughly locally.

### Phase 4: Submitting and Iterating (Days 9–10)
- Push your branch and open a Pull Request against `main`.
- Address mentor and reviewer feedback promptly.
