# Contributor Weekly Checklists

### Week 1: Setup & Exploration
- [ ] Forked repository and successfully ran project locally.
- [ ] Joined community communication channels.
- [ ] Claimed a `good first issue`.

### Week 2: Implementation
- [ ] Created feature branch and implemented the requested change.
- [ ] Verified local tests pass without errors.
- [ ] Drafted clear PR description referencing the issue number.

### Week 3+: Review & Beyond
- [ ] Addressed all reviewer comments.
- [ ] PR successfully merged! 🎉
- [ ] Picked up a second intermediate task or helped review another contributor's question.
